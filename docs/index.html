AAPI
Automatic API Builder

Build production-ready GraphQL APIs with MongoDB in seconds

Get Started View on GitHub 
# Install AAPI globally
npm install -g aapi

# Create a new API project
aapi create my-api --secure

# Start developing
cd my-api
npm install
npm run dev

# Your API is live! 🚀

What is AAPI?

⚡

Lightning Fast

Generate complete GraphQL APIs with Apollo Server or GraphQL Yoga in seconds. No boilerplate, just pure productivity.

🔒

Production Ready

Built-in security features: JWT authentication, RBAC, rate limiting, input sanitization, and comprehensive audit logging.

🧩

Flexible & Extensible

EJS-based templates, auto-discovery of resolvers, and clean modular architecture. Customize everything to your needs.

📦

Zero Configuration

Start with sensible defaults. MongoDB + GraphQL integration works out of the box. Scale when you need to.

Features

Core Features

  • ✅ One-command project setup (aapi create <project>)
  • ✅ Automatic MongoDB + GraphQL integration
  • ✅ Model generator (aapi generate model <Name>)
  • ✅ JSON schema import - Auto-detect fields!
  • ✅ GraphQL Yoga (default) or Apollo Server
  • ✅ Auto-discovery of resolvers (no manual imports)
  • ✅ Dynamic EJS-based templates
  • ✅ Clean modular file structure
  • ✅ 100% ES Modules
  • ✅ Open-source & MIT licensed

Security Features (--secure flag)

  • 🔐 JWT Authentication (access & refresh tokens)
  • 🛡️ Role-Based Access Control (RBAC)
  • ⏱️ Rate Limiting (DDoS protection)
  • 🧹 Input Sanitization (XSS & NoSQL injection prevention)
  • 📋 Security Headers (OWASP recommended)
  • 📝 Audit Logging (MongoDB TTL, 90-day retention)
  • 🔒 Account Locking (after 5 failed attempts)
  • 🌐 CORS Protection (configurable whitelist)

Installation

Global Installation (Recommended)

npm install -g aapi

Install AAPI globally to use it anywhere on your system.

Local Development

git clone https://github.com/tashikomaaa/aapi.git
cd aapi
npm install
npm link   # exposes the aapi CLI globally

Clone and link locally for development or contributions.

Requirements

  • Node.js: ≥18.0.0
  • npm: ≥9.0.0
  • MongoDB: Local or cloud instance

Usage

Creating a New Project

With GraphQL Yoga (Recommended)

aapi create my-api
cd my-api
npm install
cp .env.example .env
npm run dev

With Security Features

aapi create my-api --secure
cd my-api
npm install
cp .env.example .env

# Generate JWT secrets (IMPORTANT!)
npm run security:generate-secret

# Update .env with generated secrets, then start
npm run dev

With Apollo Server

aapi create my-api --apollo
cd my-api
npm install
cp .env.example .env
npm run dev

Generating Models

Manual Model Generation

aapi generate model User

Creates three files: Mongoose model, GraphQL schema, and resolver.

From JSON Schema (Auto-detect)

# Export from MongoDB
mongoexport --collection=users --db=mydb --out=users.json

# Import into AAPI (automatically detects field types)
aapi import users.json

# Or with custom name
aapi import data.json --name Product

# Preview what will be generated
aapi import users.json --preview

CLI Commands

Project Creation

aapi create <name> [options]

Create a new AAPI project.

  • --yoga - Use GraphQL Yoga (default)
  • --apollo - Use Apollo Server
  • --secure - Add authentication & security features
  • --force - Overwrite existing directory
  • --skip-install - Skip npm install
aapi init [options]

Add AAPI to existing Node.js project.

Model Generation

aapi generate model <Name>

Generate model, schema, and resolver files.

aapi import <file.json> [options]

Import models from JSON schema with auto-detection.

  • --name <Name> - Custom model name
  • --preview - Preview without creating files
  • --force - Overwrite existing files

Utilities

aapi list

List all models in the current project.

aapi --help

Show help information.

aapi --version

Show version information.
